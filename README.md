# air-link-01

聊天版的**关系记忆系统**：记的不只是「用户」，是「这段互动」。

> **它怎么工作**——先说人话，术语在下一节解释：
>
> 1. **你说一句话**，系统先替她**回想**：这句话跟以前哪些事有关、现在该不该翻记忆。
>    哪件事跟现在最相关、最近、最重要，就先递哪件；同时被多个角度命中的旧事会排前面。
>    翻出来的东西按"被几条线索同时命中"排队，只把最该想起来的两三条递到她眼前。
> 2. **她开口说话**。整条链路里只有"怎么说话"归她——算相似度、排顺序、比阈值这类
>    有确定答案的事交给代码（代码比模型可靠），"这几件事是不是同一件"这种语义判断才归她。
> 3. **说完才收进记忆**：一段对话切成一件事（一张「场景卡」）；同一主题的几件事聚成一段叙述；
>    只有反复印证出同一个模式（≥3 次，且发生在同类情境里），才升格成"她眼里的你"。
>    新证据会修正它；你说一句"不对"，它就真删。
> 4. **没说完的事另外记着**：到点提醒她一次（一次只提一件），提过就不再提，直到事情有了结果。
> 5. 她**从不主动开口**——她的话只发生在你说话之后。
> 6. 上面每一步都**留痕**：为什么想起这个、为什么没想起那个，页面上都翻得出来。

**零依赖**：Python 3.11+ 标准库，连大模型和向量服务的调用都是自己用标准库发的（`urllib`）。
**分工是硬的**：有确定答案的事——算相似度、排顺序、比阈值、判该不该切场景——一律给代码
（代码比模型可靠）；只有「这几件事是不是同一件」这种**要动脑子的语义判断**才交给大模型。
界面中 / 英双语（设置页切，她的输出跟着走；记忆内容不翻——那是数据）。

## 核心机制

**记忆分四级**：S0 原话（按天一份文档）→ S1 场景卡 → S2 主题摘要 → S3 画像——抽象度越高越不可逆，
所以分级存。`profiles`（她的推断）与 `user_facts`（你明说的事实）**分开存**：档案不印证、不老化。

**一次回应的顺序是死的**：唤醒（读）→ 拼上下文 → 生成 → 写入。唤醒必须在写入前——否则当前这句
会先混进历史，既重复注入、又让线索判断拿到"未来"。拆开是九步，**她只在第 4 步"说话"出现**，
其余六步是系统替她做的（见 [`设计与实现对照-结构.md`](设计与实现对照-结构.md) §一）。

### 唤醒（读）：先算线索，再定动作

七条线索（**每轮只一次轻量大模型调用**判 C2/C3/C5/C7；C1/C4 用向量；C6 查重）：

| 线索 | 判什么 | 命中条件 | 为什么需要它 |
|---|---|---|---|
| **C1 语义** | 这句话与全库的最高相似度 | > 0.40（向量不可用降级成字符重叠时降到 0.03——**阈值跟着降级走**，否则降级就是失忆） | **主路径**：这句话跟以前哪件事像。没它，翻记忆就只能靠关键词 |
| **C2 时态** | 这句话指向哪 | 不是 `now`（现在；past 过去 / future 未来 / 假设） | 决定往哪个方向翻：「上次那事」→ 往回翻（时间回溯）；「明天面试」→ 往前想（主题检索） |
| **C3 情绪** | 情绪倾向（valence）+ 情绪强弱（arousal） | 强弱为高（`arousal=1`）；倾向拿不准就**不动**（不确定就不作为） | 情绪上来时该想起的是**同类时刻**（不是随机一件）；顺带说明"这轮可以多想几条"（预算 +3） |
| **C4 自我相关** | 与「关于这个人」的记忆的相似度 | > 0.70，**设了上限**——防自我相关过度主导 | 这句在讲"他自己"——值得往回翻，记一票；上限是防它把别的线索压过去 |
| **C5 关系** | 是不是在说我们之间 | 是 | 在说"我们之间"（约定、关系的变化）——关系本身也是记忆，记一票 |
| **C6 新鲜度** | 1 − 最高相似度 | < 0.30 = 「你们聊过这个」 | 只用来**说一句提示**：「你们聊过这个」——指路，不是内容 |
| **C7 未决** | 是不是一件没了结的事 | 是（它是**这句话**的属性，不落存储字段） | 在说一件**没了结的事**——没完成的事天然更该被想起来（人也是这么记的），记一票 |

（C2–C7 每条各 **1 票**：单独一条不足以下判断，但两条以上凑起来才是"多维协同"——
排序往前、R5 才给原文，靠的就是这个。）

两条**旁路**与七条并列、不经语义检索直接定位：**实体**（命中库里带个人关系的名字）与
**字面**（2–4 字的**罕见词**：在库里最多 3 个场景出现过——不查词表，"哪些词重要"是**数出来的**，
「我们」「的时候」满库都是自然被挡在门外，一条消息最多带 3 个词出去）。

线索耦合出**动作**（规则版，每条自带阈值；数学上等价于加权和，第一版不拟合权重）：

| 动作 | 什么时候 | 做什么 |
|---|---|---|
| **R0 轻量感知** | 所有输入 | 含指代 / 时间词 / 情绪词 / 实体名 / 第一人称 → 翻。**默认倾向"翻"**：该翻没翻（失忆）不可挽回，不该翻翻了只是噪声 |
| **R1 主题检索** | C1 命中，或 C2 = 未来 / 假设 | 取相似度最高的 2N 条，再**沿同主题扩散一层**（扩散算"连带想起"，不加票） |
| **R2 时间回溯** | C2 = 过去 | 按时间取最近 60 条，但**要过弱相关这道门**——「过去」本身不含相关性，不过滤就成了"把最近的 N 条全捞出来" |
| **R3 情绪匹配** | 情绪强（`arousal=1`）且倾向明确 | 取同情绪倾向的 60 条（过门才算），并把这一轮的**深度预算 +3** |
| **R4 常驻** | 每轮 | 只带**已立**（`established`）的画像（`pending`＝还没印证够的猜测，不进注入）+ 活跃摘要 |
| **R5 原文下钻** | **多维协同**才给 | 票数 ≥ 3 **且**含至少一个强维——原文最长，不给"一维命中"也不给"两个弱维凑数" |

排序**四键**：**票数 → 线索层级 → 新鲜度 → 核心度**。票按维去重、分强弱——语义 / 实体 / 字面命中
各 **2 票**，C2–C7 各 **1 票**；所以"一条旧记忆被多个维度同时命中"赢过"刚发生的一条"，同票再比新鲜。
取前 N（默认 2，情绪命中 +3），**其余进抑制名单**，连"比末位入选者差多少"一起写进留痕（trace）——
**"为什么想起这个、为什么没收"是输出的一部分**。

（上面这些阈值 / 预算 / 条数都是 `core/config.py` 里的默认值——旋钮只写一处；
线索与动作的判定在 `core/recall.py`，每一条都带着"为什么这么定"的注释。）

### 提炼（写）：什么时候写、写多深

**什么时候提取**（四条触发，任一满足）：话题切换（**主路径**——切场景和提取触发是同一件事）·
超 M 轮没切换 · 窗口字词量（token）超预算（只压最老的一批，尾部保留逐字）· 会话结束。
会话与会话之间还有**体检**兜底（按量 / 按时触发：封顶的提炼 + 画像复核）。

**一次提取同时产出两样**：回窗口的摘要（替代被压掉的逐字）与进长期库的场景卡——
**压缩 = 提取**，不是两套逻辑。提取单元是**话题段**不是一轮（一句话构不成场景，太碎）。
没信息量的一段**只留摘要、不落卡**：跳过只该意味着"不进长期库"，不该意味着"当没发生"。

| 层 | 从哪到哪 | 性质 |
|---|---|---|
| 提炼 1 | S0 原话 → S1 场景卡 | 结构化，**不下结论**；顺带落原文、实体索引、未了结 → 备忘录 |
| 提炼 2 | S1 → S2 主题摘要 | **聚合**（可逆），**不下结论** |
| 提炼 3 | S2 → S3 画像 | **抽象**（不可逆），**下了结论** |

下结论的那一层才有**四道关**：**≥3 次印证且同情境**（触发情境类别 `trigger_class` 相同 + 触发语
语义相近——不同情境下的同类反应不算同向收敛）· 出处（`sources`）必填（可追溯）· 跨来源计数
（你说的话只算你本人表达）· 长期不印证 → 降回待印证（`pending`）。升级之后靠**持续修正**：
新证据判维持 / 修正 / 推翻（holds / revise / overturn），修正时旧记录填作废时间
（`invalidated_at`）进历史、新记录另起（双时间戳因此能回答"某个月它眼里的你是什么样"）；
**人的否决 = 真删**。

**编辑 / 重说只作用于窗口**：改一句或重新生成，是撤掉窗口里那一轮（和它后面那些）再说一遍——
被撤掉的那些**从没进过长期库**，撤掉就等于没说过。反过来同样成立：**已经提取落库的那段不回改**
（界面上它只有复制与朗读）。于是有一条要记住：**记忆是快照，不是视图**——落库那一刻记下的是
"当时真的说了什么"，之后窗口里怎么改都不回写它。要改已经落库的那条，改的是**理解**
（「场景」页改 / 归档场景、摘要、画像，改动留痕），原文（S0）**不可改**；要作废，走归档或真删
（真删只有人能发起）。

### 未了结 · 她的手 · 落痕

- **未了结**（备忘录）：没闭合的事（含她自己的承诺）——**到点 → 进注入（一次一件，进了就算提过）
  → 命中判定（变更 / 完结）→ 超期退役**。「到点」只是"有资格进注入"，提不提是提示词里的分寸；
  她**从不主动开口**——她的话只发生在你说话之后。
- **她的手**（工具箱）：5 个工具、三档权限（自主 / 只读 / 需确认）；红线终审**单调**（只有拒绝
  没有允许）；每次调用留痕。
- **落痕**：每次唤醒一行留痕（JSONL——一行一条的文本文件）、每次工具调用一份、每次整理一份——
  仪表盘就是把它们画出来。
- **关系全是派生的**：没有边表——引用 = 出处（`sources`）、相邻 = 主题 + 时间、原文 = 按天文档、
  "被引用那一刻" = 画像上的时间戳（`profiles.evidence_at`）。

五个阶段（最小闭环 / 画像与印证 / 备忘录与镜像 / 渐变检测 / 对话层与实验台）都已走完。

## 三条硬约束（写代码时别绕开）

1. **数据不丢**：任何路径（崩溃 / 大模型失败 / 字段缺失）都不**静默**删除已写入的场景；库损坏 →
   备份 + 报错、拒绝重建；归档只置标记（可逆）、老化只降状态；**真删只有人能点**。
2. **降级不崩**：大模型失败给保守默认值、向量不可用走字符重叠——降级会变糙，但不该变哑。
3. **S0 不进自动唤醒**：原文没有索引，自动唤醒要原文只能经场景编号下钻
   （打捞是唯一例外，且只由人发起）。

## 跑起来

```bash
python -m core.dashboard        # 记忆实验台（推荐起点）：左边聊，右边实时看想起了什么、为什么
python demo.py                  # 阶段 1 演示：对话 → 记住 → 想起来（打印完整推理链）
python demo_distill.py          # 阶段 2：聚合 → 抽象 → 印证 → 修正 → 老化 → 否决
python demo_memo.py             # 阶段 3：备忘录 → 到点进注入 → 命中判定 → 退役
python demo_trend.py            # 阶段 4：渐变检测（数字漂了 ≠ 人变了）
python run_experiment.py --script 你的脚本.json --fresh     # 对话回放 + 报告（同一段可反复跑）
python -m unittest discover -s tests                        # 629 个测试，离线（模拟的大模型 + 模拟向量）
```

- **实验台**：左边聊，右边实时显示这一轮的线索、动作、召回（含为什么）与抑制名单；下面标签页查库
  （场景 / 摘要 / 画像 / 备忘 / 实体 / 主题 / 打捞 / 留痕），顶栏可切人格与语音。
- **Windows 双击入口**：`run.cmd`（带窗口）· `start.vbs`（不开黑框，语音服务一起起）·
  `switch.vbs`（桌面小开关，一拉一关）。中文名的 `启动.vbs` / `开关.hta` 是正本，纯英文名的两条是别名。
- `run_experiment.py` 的实验素材是**私人的，仓库不随带**（脚本格式见该文件头部）。

### 用真实模型

```bash
export AIR_LINK_LLM_ENDPOINT=https://api.example.com/v1
export AIR_LINK_LLM_API_KEY=sk-xxx
export AIR_LINK_LLM_MODEL=your-model
export AIR_LINK_EMBEDDING_ENDPOINT=https://api.example.com/v1   # 或 local://<模型名> 走本地
export AIR_LINK_EMBEDDING_API_KEY=sk-xxx
export AIR_LINK_EMBEDDING_MODEL=text-embedding-3-small
python demo.py --real
```

也可以把 [`config.example.json`](config.example.json) 复制成 `config.local.json` 再填
（实验台「设置」页写的是同一份文件）。优先级：默认 < `AIR2_*` < `config.local.json` < `AIR_LINK_*`；
密钥（key）输入框**留空 = 不改**。⚠️ **DeepSeek 不提供向量（embedding）接口**——向量得另配
本地 Ollama 或 OpenAI。
