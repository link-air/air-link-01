# air 的声音 · **接口契约**

她把一句话念出来。主项目只通过**一个 HTTP 地址**和它对话（`config.local.json`）：

```json
{ "tts": { "endpoint": "http://127.0.0.1:8977" } }
```

不写就是默认这个地址；**留空 = 不调语音**。

## 为什么仓库里只有契约

实现不进库（2026-10-07 定）——它绑的是这台机器：CUDA、几个 G 的模型权重、一份私人音色配置。
这三样公开价值都低于隐私成本，所以服务本体和它的配置留在本机（`.gitignore` 挡住），
仓库里只留这份契约：**要出声，接一个符合契约的服务；不接，主项目一切照旧**
（语音是可选外挂——没接上时界面如实说"没接上"，别的功能不受影响）。

主项目这边**已经为调用方准备好的一切**：

- **界面**：每条她说的话下面有个喇叭（再点一下＝停）；顶栏那个喇叭是**自动朗读**（状态存在这台浏览器里）。
- **转发与降级**：`core/dashboard.py` 把 `/speak` 的帧流原样转给页面；流式失败（老服务 /
  浏览器不给读流）→ 退回整段 + `<audio>`。两条路的声音是同一份。
- **语气参数**：界面上的刻度是**每次请求带的参数**，不是加载时定死的东西——下一句就生效。

## 契约（三个端点）

### `GET /health`

```json
{"ok": true, "model": "...", "speaker": "...", "model_kind": "custom",
 "ref_anchor": "", "instruct_extra": "...", "loaded": true,
 "dims": {"speed": ["语速", ["很慢", "偏慢", "", "稍快", "快"], 2, 4], "…": "…"},
 "speakers": ["aiden", "ryan", "…"], "speakers_all": ["…"]}
```

| 字段 | 说明 |
|---|---|
| `dims` | **有哪些刻度可调**：id → `[标签, [各档描述], 默认下标, 最大下标]`。**页面不抄一份**，抄了就会跟服务漂移——刻度长什么样由服务端说了算 |
| `speakers` / `speakers_all` | 能用的音色（后者含"界面上不出现"的那些——**挡掉 ≠ 禁用**，勾「显示全部」还能选回来） |
| `loaded` | **只表示"现在在不在显存里"**——没念过、或空闲放掉了，都是 false。两种情况对调用方一样：下一次播报要等它读权重 |
| `instruct_extra` | 服务端的默认声音描述（调用方没给时它兜底） |

### `POST /speak`

```json
{"text": "要说的话",
 "speaker": "serena",                  // 可选：基底音色
 "dims": {"speed": 3, "pitch": 2},     // 可选：刻度（整数下标；缺 = 不动）
 "instruct_extra": "像刚睡醒",          // 可选：一句声音描述（不给 = 用服务端默认）
 "instruct": "",                       // 可选：直接给的指令串
 "stream": true}                       // 可选：帧流（见下）；不给就回整段
```

- `text` 必填：空 → `400`；写坏的字段按"没给"处理（**降级不崩**）——这些值是人从界面拖出来的，写错也该照常出声。
- `stream` 不给 → 回整段音频；给了 → 回帧流。
- **开始前就炸的错，要是干净的 `500` JSON**：流式也一样 —— **先摸到第一帧，再发响应头**。
  发完 200 再断在半路，页面就分不清"没声音"和"没接上"了。

### `POST /shutdown`

**让它自己退**（先把话说完再死）。这样显存干净放掉、正在生成的那句能收尾，
而且**不管服务是谁起的都能关**——外面猜 PID 然后 taskkill 是杀错进程的做法。

## 帧格式（`stream: true`）

```
12 字节头：`ARAU` + 采样率 u32 + 声道 u16 + 保留 u16   （小端）
之后重复：  样本数 i32 + Int16 PCM（样本数 × 2 字节）
```

**一份约定，三处实现**：生成端（服务）· 转发端（`core/dashboard.py` 的 `_pcm_stream`）·
拆帧端（`web/index.html`，搜 `ARAU`）。改一处必须改另两处；仓库里那两处由
`tests/test_phase5.py` 的 `FrameConventionTest` 钉着。

页面为什么不用 `<audio>`：它要整段文件，而 WAV 喂不进 MediaSource。页面把 PCM 排进
AudioContext —— 一帧进来就排在"上一帧结束的时刻"上，接缝是连续的，不靠 `setTimeout` 对齐。

## 本机那份实现
